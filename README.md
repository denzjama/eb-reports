# Employer Brand Reviews

Source of https://denzjama.github.io/eb-reports/ — public employer-brand reviews made with [Employer Brand Auditor](https://github.com/denzjama/employer-brand-auditor).

- `docs/<company>-<yyyy-mm>/index.md` — the article (also imported to Medium with a canonical link)
- `docs/<company>-<yyyy-mm>/report.html` — the full report
- `tools/` — `report_to_article.py` (report → article) and `publish_medium.py` (Medium API, for accounts that still have an integration token)
